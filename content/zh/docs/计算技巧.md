## 百分数化分数 {#百分数化分数}

求增长量：
增长量 = 现期 \* r / (1 + r) = 现期 / (n + 1), n = 1 / r, r 是百分数，n 是分数。

## 等比放缩 {#等比放缩}

A/B = a/b = (A +- a) / (B +- b)

45.5 \* 111 / 108
竖看差值，111 - 108 = 3 斜看比值，455 / 108 = 4 比例放缩： 455 + 3 \* 4 = 467

8100/9798 = 8100/9800 = (81 + 1.6) / (98 + 2) = 82.6%
因为 81/98 = 81/100 = 0.8, 0.8\*2 = 1.6

计算时可以忽略百分号（当作把百分号提到外面）
45.5/39.8% - 39.2/38.6% = 455/398 - （392+12)/(386+12) = 51/398 = 51/400


## 直除 {#直除}

望二看三
选项通常前两位就区分出结果。除法时先看除数前两位，看能商几，再看除数第三位，看是否会导致进位
761/1281  12\*6=72 8\*6=48 72+4=76 因此商 5


## 误差分析 {#误差分析}

乘除法： 真实值/ 四舍五入误差 = 真实答案/ 答案误差
606 / 30.3 = 20   606 / 30 = 20.2
30 / 0.3 = 20 / 0.2

1860/119 = 1860/(119+1) = 15.5
误差 1/119, 表示误差为一份。 15.5 是 119 的 0.1 倍多，误差也是 一份 0.1 倍多，因此会是 15.6 多一点
